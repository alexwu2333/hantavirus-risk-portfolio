Key Drivers

    Planning Actions

      Data and method

      Where the signals come from

      The current MVP uses clearly labeled demo data so the full product can run locally. The production data plan connects official public-health surveillance with climate, population, and land-cover features.

      Current MVP

      Demo training data

      State-year rows in the repository simulate surveillance-style, climate, and habitat features. They are only used to validate the pipeline, API, and website workflow.

      Public health

      CDC / NNDSS

      Future official disease counts should come from CDC NNDSS annual or weekly surveillance data. Hantavirus is sparse, so the model is framed as risk-level classification.

      Environment

      NOAA and land signals

      Temperature, precipitation, drought, rurality, forest cover, and habitat proxies are used as explainable signals connected to exposure conditions.

      Output

      Risk level, not diagnosis

      The website predicts low, medium, or high state-level public-health risk for planning. It does not predict whether a person is infected.
